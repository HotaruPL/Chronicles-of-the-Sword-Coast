TORMCH - Torm's Hand Circular Chamber

Standalone custom area using the verified TORMHA/TORMFO PVRZ/TIS/WED pipeline.
Current baseline contains artwork only: no actors, regions, entrances, containers or area script.
Artwork is uniformly reduced to 75% from the previous working 21x18-tile version and fitted into a 16x14 IE-tile footprint (1024x896). No new artwork was generated.
Search map is temporary/all-passable and will be replaced when collision is drawn.
