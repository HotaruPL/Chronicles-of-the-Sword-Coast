VERSION 0.3 - BG1 MERCHANTS (FIRST IMPLEMENTATION)
==================================================
Item component (index 0) is unchanged from v0.2. BG1 merchants are a NEW
installation component (index 1); install it separately after the items.
It is EET-only due to BGxxxx resource names. No earlier QC mod components touched.

BG1 merchants: 10, with NPC CRE/DLG/area actors. Each store has only
its specified stock: 10 finite units of each item. All custom resources
retain QC prefix. Selling ordinary goods to the merchant using the
standard store Sell button is disabled intentionally. Specific-price

Sellers can buy one unit at a time, even out of stacked quantities.

If you tested BG1 maps in an old save already, it is safer to test using
an area that has not been visited/saved, because explored-area ARE resources
may already have been serialized into your save.

commoner, halfling, or dwarf animation slots, with assigned clothing colors.
Please verify these visually in game before freezing this build.

Further components for Siege of Dragonspear, BG2 and Throne of Bhaal
are NOT included in v0.3. Existing Horst store and the special Felicia
exchange remain unmodified in this incremental BG1 test release.

VERSION 0.4 - BG1 MERCHANT BUGFIX
==================================================
The v0.3 merchant dialogues allowed repeated sales because a trade
immediately returned to the same dialogue state; item-presence options
could remain available before the party inventory was re-evaluated.

FIX: Each successful fixed-price exchange takes exactly one unit,
pays exactly once, then closes dialogue. Talk to the merchant again
to make another sale. This applies to Eustache, Evelyn, Bronya,
Orina, Cindel and Will.

Evelyn, Bronya, Orina and Cindel now use the BG1 female PROSBA_B
creature as the base rather than MERCH2 (with their existing
requested visual animations/palettes unchanged). Both CRE sex and
gender bytes are explicitly set to female.

NOTE FOR OLD SAVES: Areas/creatures already stored in a saved game
might continue using the old dialogue or old voice even after
reinstalling. Test with a save BEFORE the first visit to the area,
or load a fresh/new game, or use C:CreateCreature("QCMM09") to
spawn a test instance from the newly installed CRE. Dialogue files
are rebuilt in override, but already-instantiated CRE instances
can retain their previous sound data.

This is a narrowly scoped correction. Items, icons, prices,
inventories, coordinates, and planned later merchants remain unchanged.
